# Product Thinking

Personal learning project on product thinking for solo builders using coding agents.

- `MISSION.md`, `NOTES.md`, `RESOURCES.md`: learning plan, notes, and sources
- `lessons/`: single-file HTML lessons
- `weekend-build.html` + `weekend-build-assets/`: **Weekend Build!**, an anime visual novel with 7 endings that teaches Marty Cagan's Four Big Risks
