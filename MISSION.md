# Mission: Product Thinking

## Why
Build better apps of my own, including apps I build with coding agents, by deciding what's worth building (and what isn't) before spending time building it.

## Success looks like
- Before starting a project, I can name its riskiest assumption and test it cheaply.
- I can turn a feature idea into a clear problem for a specific user.
- I cut or change project ideas based on evidence, not on how fun they are to build.

## Constraints
- Some informal experience: I've built things and thought about users, but never studied product thinking.
- Lessons must be short, interactive, and a single HTML file each.

## Out of scope
- PM career skills (roadmaps, stakeholder management, PM interviews).
